# SIAHSSR Frontend

React + Vite frontend for the SIAHSSR site. See the root `README.md` for full setup
instructions (database, backend, and first-admin steps).

Quick start:
```bash
npm install
npm run dev      # http://localhost:5173
```

Requires the backend running on `http://localhost:5000` (or set `VITE_API_URL` in `.env`).
